**The numbers are sound.** Every headline number in Results (balance, agreement, head-to-heads, configurations, labels, plasmode, MIMIC-IV) matches its source to the printed precision, and Table 1 matches `quality_tiers.json`, `TRIAL_LABELS.json` and the paper.md / `table1_picot.md` PICOT columns for all 38 trials. ### Fixes (all applied to paper2.md unless stated)

1. **Figure 1 flag range (MISMATCH, figure bug; fixed in code and regenerated).** Figure 1 and its legend gave 426–621 flags. `make_paper2_figures.py` matched `log.json` trial names (registry ids with hyphens, e.g. `protect-af`) against tier keys (underscores, e.g. `protect_af`), so only 18 of the 32 S32 trials were counted and PROTECT AF (622) was dropped. The correct range is 426–622 in both S32 and S38. The script now maps registry → key and asserts 32 trials. Only `figure1_study_design.{png,pdf}`, `index.html`, `check_values.json` and the audit-folder HTML copy changed; every other PNG regenerated byte-identically (the other PDFs differed only in metadata and were restored).
2. **Median cohort size (MISMATCH):** 4,729 → 4,730 (median 4,729.5).
3. **CLMBR-T 32-PC head-to-head misattributed (MISMATCH, l.97):** the −2.9% (−10.1 to 4.4) is PS-Demo + CLMBR-T(32) vs PS-Flags, not CLMBR-T(32) added to PS-Flags. Reworded.
4. **Benchmark-permutation q for the gradient-boosted PS (MISMATCH, l.111):** ".89" is the |Δ log HR| q; the q for the benchmark-permutation P = .005 is .43 (and for 1:3 matching, .43 for |Δ| and .52 for the permutation test). Corrected.
5. **Domain differences "did not replicate across configurations" (MISMATCH, l.93 and l.210):** true for the ECG's echo-domain advantage, false for CLMBR-T's lab/vital advantage over the ECG, which reached q < .05 in 4 of 6 configurations (and for other labs in main, q = .045). Reworded in Results and Discussion.
6. **"Balance contrasts that reached q < .05 ... none involved PS-Flags" (MISMATCH, l.89):** true for the primary endpoint (m54); in the balance family as a whole `Flags: shufCLMBR vs base` (a placebo worsening) also reaches q < .05. Qualified to "for the primary balance endpoint".
7. **Rhythm/conduction label analysis (MISMATCH, Methods l.71):** Methods said the panel has no rhythm measures, but heart rate was used as a tested proxy (`labels_domain.csv`, `tested = True`; Figure 4C). Added.
8. **MIMIC-IV CIs (MISMATCH, Methods l.63/l.67):** Statistical analysis states 4,000 resamples; MIMIC used 2,000 (v20 convention) with nominal P values. Added to the External replication Methods.
9. **Permuted ECG under overlap / GBM (MATCH; clarified, l.109):** "q ≈ .05" is q = .050 and .045, i.e. these placebo-worsening rows are among the 98 rows with q < .05. Stated explicitly.
10. **hdPS + ECG not placebo-controlled (UNSUPPORTED as ECG-specific, l.89, l.210, l.220):** the ECG's 7.6% gain at the hdPS (q = .033) is not distinguishable from the permuted ECG at that rung in the main configuration (ECG vs permuted ECG 4.8%, −2.4 to 12.0, q = .26; permuted ECG vs base 3.0%). Caveat added in Results, Discussion and Conclusion.
11. **"Performs about as well as a large hand-built flag set" (UNSUPPORTED, equivalence-type, l.212):** replaced with "no detectable difference ... the data do not establish equivalence" (HANDOFF §1 and audit S1).
12. **"CLMBR-T performed about as well as ... measured clinical covariates" (UNSUPPORTED, l.220):** CLMBR-T was nominally worse than PS-Clinical (−4.9%) and significantly worse under the GBM PS (−11.9%, q = .007). Conclusion reworded.
13. **"This restriction did not explain the CLMBR-T gain" (UNSUPPORTED as stated, l.85):** the source says restriction may contribute (15-trial small-loss subset 9.3% vs 15.3% in the other 17). Softened to the source's wording.
14. **Agreement by quality tier (MATCH; context added, l.119):** CLMBR-T 0.072 vs 0.049 is correct, but the permuted ECG shows a larger tier difference (0.030 vs −0.027). Added, so the tier contrast is not read as a signal.
15. **CV-tuned PS-Flags agreement (MATCH; completed, l.99):** the text gave main and overlap but omitted 1:3 matching, where the result held (P = .038, benchmark-permutation P < .001). Added.
16. **Spearman check (MATCH; completed, l.117):** added the permuted-ECG correlation (ρ = 0.19, P = .31) so both placebos are shown.
17. **IPTW interpretation (MATCH; hedged, l.101):** "This reflected" → "This most likely reflected" (the ESS evidence is indirect).
18. **Discussion, agreement (MATCH; qualified, l.214):** "reassigning RCT results gave reductions as large" holds in most, not all, configurations (ECG: 1:3 matching permutation P = .037, GBM .005, both nominal). Qualified.
19. **Flags median (MATCH; clarified, l.39):** 529 is the 38-trial median (S32: 532.5); the range 426–622 is the same in both sets. Stated.
20. **[CHECK] markers resolved and removed:** CLMBR-T-base facts (141 million parameters, 2.57 million Stanford patients, 768 dimensions); PS-CVD5 matched pairs; PS-Demo arm values; PS-Flags + ECG; Figure 5D quality-tier gain; Figure 1 flag count; refs 22 and 23. Details in §3.
