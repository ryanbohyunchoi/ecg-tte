# S11 (exploratory, post hoc): demographics + 5 disease codes (HTN, T2D, CAD, AF, HF) ± ECG, 33 trials (2026-09-27)

This is the v1.7 P2 design without obesity. The code path is identical (`scripts/v17/s11_p5.py` monkeypatches `v17_confirm.P2DX`). P1 rows reproduce `results_all.csv` exactly (max |Δlog HR| = 0).

**Outputs** (in `claude-v17-confirm/`):
- `results_p5.csv`, where the ps label "P2" means P5;
- `summary_p5.csv`.

**Tests.** One-sided exact sign-flip is used, with Monte Carlo sign-flip for 33 trials. The shuffled-RCT test draws benchmarks from all 33 RCTs.

- lt = % of the 58 held-out covariates with |SMD| < 0.1;
- x = % of the covars2b non-proximal panel with |SMD| < 0.1;
- gap = |Δlog HR| vs RCT.

**Comparison.** Across the 33 trials, the gap narrows as follows:
- P1 (demographics only): 0.258 → 0.208, p = 0.004;
- P2 (+6, incl. obesity): 0.214 → 0.197, p = 0.078, not placebo-specific;
- P5 (+5, no obesity): 0.237 → 0.192, p = 0.003.

**Interpretation.** Adding obesity to the PS removes much of what the ECG adds. This is plausibly because ECG voltage and axis encode body habitus.

**Caveats.** This PS was defined after the v1.7 results were seen, and the new-15 confirmation is not significant.


## Round-4 audit corrections (2026-09-28; docs/v18/AUDIT_ROUND4.md §7)
- Sign-flip tests for 33 trials are **exact (full enumeration)**, not Monte Carlo.
- The explanation that obesity removes the ECG gain because ECG voltage encodes body habitus is speculation. It has not been tested.
